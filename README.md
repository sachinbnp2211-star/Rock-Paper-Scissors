# 🎮 Rock Paper Scissors

A responsive and interactive Rock Paper Scissors game built with HTML, CSS, and JavaScript.

The project includes persistent game statistics using browser Local Storage and a dedicated statistics dashboard to track gameplay performance.

## 🚀 Live Demo

[Play Rock Paper Scissors](https://sachinbnp2211-star.github.io/rock-paper-scissors/)

## ✨ Features

- 🎮 Interactive Rock Paper Scissors gameplay
- 📊 Dedicated statistics dashboard
- 💾 Persistent game data using Local Storage
- 🏆 Win, loss, and draw tracking
- 🔥 Win streak tracking
- 📈 Win-rate and gameplay statistics
- 🕒 Recent game history
- 🔄 Reset statistics functionality
- 📱 Responsive design for mobile, tablet, and desktop
- 🎨 Modern and interactive user interface
- ⚡ Lightweight frontend application
- ♿ Accessible and keyboard-friendly controls

## 🛠️ Tech Stack

- **HTML5** — Page structure and semantic markup
- **CSS3** — Responsive design, styling, animations, and layout
- **JavaScript (ES6+)** — Game logic, DOM manipulation, event handling, and statistics
- **Local Storage API** — Persistent storage of game statistics
